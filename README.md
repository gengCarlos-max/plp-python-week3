# Grade Reporter & Bug Hunt

## Files

- `grade_reporter.py` - Uses a for loop and if/elif/else conditions to calculate grades, pass count, fail count, and average.
- `bug_hunt.py` - Finds and fixes three bugs in a while loop program that calculates the sum of numbers from 1 to 5.

The hardest bug to find in Part B was the while-loop condition because it did not produce an error message. I knew something was wrong because the program ran successfully but printed 10 instead of the expected answer, 15.
